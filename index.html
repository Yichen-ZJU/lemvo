03 PAPER NARRATIVE + PAPER PRODUCTION

A clear research story. A compelling paper.

Paper Narrative starts with your contribution and shapes one scientific story across the question, insight, method, and evidence. The abstract captures the discovery; the introduction builds the problem; sections and figures advance the argument; the conclusion answers the opening question and leaves a new understanding.

Research findings feed one shared narrative plan across the abstract, introduction, figures, and conclusion. As discoveries evolve, the story and manuscript stay aligned. Scientific figures, citation checks, and dual review carry the paper through to delivery.

BUILT FOR CONTINUOUS RESEARCH

Research that keeps its thread—and moves forward.

Project memory, launch conditions, and cumulative budgets connect every turn. Turn preparation into a probe, diagnosis into a change, and results into the next action.

01 / REMEMBER

Continue from the progress you have

Save the question, findings, decisions, and next action in project files. Read the state and findings before continuing, keeping the existing contract, ledger, and best result.

state · findings · decisions
02 / START SMALL

Ready to run? Start small.

Launch the smallest real probe when the implementation runs, measurement is valid, and budget permits. Track preparation costs and specific blockers to move toward an observable result.

ready → probe → observation
03 / LEARN & REVISE

Turn diagnosis into a change

Fix measurement or implementation issues where they occur. Revise or replace an ineffective candidate and test again. Informative negative results help choose the next step.

diagnose → revise → retest
04 / STAY IN SCOPE

Preserve the budget and the work

Carry resource records through continuation, pivots, and handoffs. At an agreed boundary, explicitly continue, narrow, or conclude with code, results, and findings preserved.

continue · narrow · conclude

Research records connect experiments and writing: establish the findings, then shape a mature contribution into a paper.

Install uv first, then run these commands from the cloned repository. Start Codex once to create its configuration.

uv tool install arxiv-mcp-server
claude mcp add --scope user arxiv -- "$HOME/.local/bin/arxiv-mcp-server"

Restart the CLI and check that arxiv tools loaded. Adjust the command if you use a custom installation path.
